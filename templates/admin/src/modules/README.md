# 业务模块

按业务域组织，如 `modules/payment/`。页面通过该模块的 `index.ts` 使用业务能力；域内可以组合接口、维护业务状态和复用业务组件。不同域不直接引用对方内部文件，稳定的公共能力抽到 shared 或公共组件。

`shared/useQuery` 支持加载、错误、重试、取消及过期结果隔离。传入的 load 必须用 useCallback 保持稳定，查询参数变化时再改变依赖。只用于查询，写操作不可放入自动执行的 effect。

`shared/useMutation` 用于用户明确触发的写操作，阻止重复提交，不自动重试。调用方捕获错误；只有成功后才关闭弹窗或刷新列表。业务权限的最终判断由后端执行。

页面不得跨域复制状态字典、金额/日期规则和接口适配。复用应基于稳定业务含义，不把不同业务强行合成带大量开关的巨型组件。
