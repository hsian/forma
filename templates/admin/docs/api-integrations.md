# 接口对接记录

复制后端的接口备注与需求说明交给工具，再查询接口文档，不要求产品填写技术字段。每个实际接入的能力单独记录：

- 业务能力 ID、用途、调用页面/模块。
- 接口文档位置、核对日期、请求方式和完整路径，不能仅凭接口名匹配。
- 页面输入到路径/查询/请求体的映射；分页、日期、字典和空值约定。
- 响应运行时校验、成功判定、业务字段提取、错误信息、登录失效约定。
- 模拟数据与真实环境切换方式，测试环境验证结果。
- 待后端确认的问题；尚未确认的关键字段不能猜测为已完成。

每个接口允许独立格式，同一模块的详情与保存也可以不同。数据库字段长度不替代需求的输入限制。未知响应抛出可定位错误，不静默替换为成功或空列表。

开发联调：复制 `.env.example`，填写代理地址；不同环境使用 Vite 的 `.env.development` / `.env.staging`。`VITE_` 值会进入前端产物，仅放公开配置。HTTP 错误在 request 层处理；业务错误在具体适配层处理。真实请求失败时不得回退模拟成功。
