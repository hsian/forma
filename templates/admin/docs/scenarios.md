# 页面场景组合

场景是开发与验收约定，不限制产品的页面外观；同一项目可组合多种场景。

| 场景 | 复用基础 | 行为和验收 |
| --- | --- | --- |
| 查询列表 | PageQuery / PageResult、useQuery、QueryBoundary | 查询参数与分页分离；条件变化重置页码；过期请求不覆盖新结果；检查空态、错误和重试 |
| 新增/编辑 | useMutation、Ant Design Form | 详情加载后回显；以业务标识更新；本地校验；提交禁用；失败保留输入；成功才关闭并刷新 |
| 详情 | useQuery、QueryBoundary | 路由标识改变重新查询；明确缺失记录、无权限和加载失败 |
| 审批 | useMutation、后端返回的可执行操作 | 后端决定权限和状态流转；二次确认；不自动重试；成功重新查询状态；测试环境验收 |

具体业务模块组合这些基础能力，页面负责布局。不要另起一套请求、加载或提交状态管理，也不要把审批规则写死到通用表单。
