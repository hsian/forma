# Forma 业务应用

这是从管理后台模板初始化的独立 React + TypeScript + Ant Design 工程。

## 运行与构建

需要 Node.js 22 或更高版本。在此目录执行 `npm install`，然后执行 `npm run dev`。
执行 `npm run build` 构建，部署 `dist/` 目录。路由使用 hash，刷新不需要额外路由回退配置。
首次安装会生成 package-lock.json，请将其提交到项目版本库，后续使用 npm ci。

模板 1.1 增加分层检查和公共能力目录。先阅读 `docs/architecture.md` 与 `capabilities.json`；运行 `npm run check` 检查依赖方向与类型，`npm run build` 也会执行这些检查。业务模块放在 `src/modules/`，每个接口在 `src/services/` 独立适配。可复用查询、写操作与加载/错误/空态组件；场景组合与验收规则见 `docs/scenarios.md`，接口示例见 `docs/endpoint-example.md`。

也可在 Forma 中间顶部选择「真实预览」，由项目维护者启动开发服务。它会读取本工程的 Vite 配置与手写扩展，并在保存生成源码后重新加载实际页面。缺少依赖时仍需先执行 `npm install`。Forma 的预览进程与维护者手动运行的 `npm run dev` 相互独立；编辑器提供停止、重试和运行日志。「交互预览」可正常操作业务交互；「编辑模式」可点击带有已登记组件编号的元素，在右侧编辑属性并自动保存到工程。手写扩展中没有对应编号的内容仍需手动维护。真实预览中的输入与弹窗打开状态会随重新加载重置；拖拽和缩放仍在「画布编辑」完成。选择浮层仅注入 Forma 管理的开发预览，不随业务工程发布。

## 修改边界

默认按设计页面独立展示，不自动增加项目名、侧栏、页头或「切换导航」按钮；画布保持设计尺寸并在可用空间居中，页面背景向视口延伸。需要模板后台导航时，维护者可在 `src/config/app.ts` 显式设置 `layout: 'admin'`；未配置或设为 `page` 都只显示设计内容。hash 路由在两种布局中都可直接访问和刷新。

- `src/pages/generated/Page-页面名-稳定标识.tsx`：每页独立的 React 页面模块，包含有类型的页面定义，引用共享运行组件；保存后自动更新。
- `src/pages/generated/routes.tsx`：自动维护的页面路由，按需加载对应页面模块。
- `.forma/snapshot.json`：同步生成的页面快照，供兼容旧入口与备份使用。
- `.forma/generated-files.json`：受管理源码的哈希记录，用于检测手写修改并清理已删除页面对应的文件。
- `.forma/runtime/`：初始化时固定的共享页面运行器与 request 基础能力；多个页面共用，当前不会自动升级。
- `src/config/app.ts`、`.env`：开发者维护的应用与环境配置。
- `src/components/`、`src/utils/`、`src/services/`：项目公共组件、函数与接口。
- `src/extensions/`：特殊页面扩展，通过页面 ID 注册；同步不会覆盖。
- `src/Application.tsx`、`src/style.css`：模板应用框架，可由维护者调整。

普通编辑、AI 修改、新增、改名、移动、复制与删除页面，在保存后自动生成对应源码与路由，通常一秒内完成。多个页面复用运行器，不逐页复制组件实现。
不要直接编辑 `src/pages/generated/`；如果检测到手写修改，生成会暂停并保留文件，请将逻辑移入扩展目录或公共组件后点击「同步页面到工程」重试。
工程写入失败不影响 Forma 中的页面保存。待生成任务保存在数据库中，服务重启后继续；可在 Forma 项目名称下查看同步状态，在「业务工程」查看每页文件位置和错误。
升级前的工程会自动补齐页面源码。原封未动的旧版 `src/Application.tsx` 会自动接入新路由并改为默认独立展示；自定义过的入口保留。
当前仍沿用原型的固定尺寸布局与模拟交互，尚未提供可视化真实接口绑定、业务权限或发布自动化。
新基础能力提供给工具和维护者使用，不会自动把原型交互替换成真实接口。旧工程保留原模板和自定义代码，不会静默覆盖升级；维护者可在 Forma 源码目录使用 `scripts/upgrade-application-templates.ts` 显式执行增量升级。升级备份位于 `.forma/upgrades/`，不更换既有运行器、请求封装与环境配置。
工程不包含 Forma 的账号、Cookie、密钥或服务端数据库。

## 接入后台

复制 `.env.example` 为 `.env`，设置开发代理地址和公开的 API 前缀。
项目接口通过 `src/services/request.ts` 调用，可在这里接入业务后台鉴权和响应适配。
统一请求支持查询参数、JSON、表单上传、超时、取消、HTTP 错误与登录失效回调，不自动重试写请求。
开发代理不参与正式构建；正式环境需配置同源 API 网关或后台 CORS。
该工程是客户端页面应用；支付签名、数据库访问等服务端能力必须由后台提供。

## 版本与删除

模板版本记录在 `.forma/project.json`；页面快照记录导出时间与页面修订号。
请用 Git 管理整个工程（包括 `.forma`），源码备份与 Forma 数据库备份分别进行。
Forma 固定原型版本目前不包含源码。删除 Forma 项目会保留本地工程，避免误删维护者代码。
