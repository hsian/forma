# Sketch 导入的支持范围与验收

转换器版本：2.0.0。验证过的真实源文件：企财.sketch，Sketch 2025.2.2，格式版本 173。

这是结构化设计稿到原型数据的转换，不是 Sketch 原生渲染引擎。支持范围必须和测试证据一起维护；不能将“JSON 转换成功”当成外观验收通过。

## 使用流程

项目菜单「导入 Sketch」→ 选择文件和画板 → 等待预检查 → 查看具体图层报告 → 生成新页面。

- 没有已知问题：可直接生成新页面。
- 有外观差异：默认不能生成；阅读报告并勾选接受差异后才能生成。
- 有无法生成的图层、缺失组件或资源等错误：阻止生成，接受差异也不能绕过。
- 转换、校验和大小检查全部通过后，在一个数据库事务中追加页面和文档；不覆盖同名页面，不留下失败的空页面。
- 页面菜单「查看导入报告」可查看、下载保存的报告。只读成员可以查看，不能导入或修改。

报告包含图层名称和原始 ID、处理说明、Sketch/转换器版本；新页面还记录源文件 SHA-256、源页面和画板 ID、导入时间、账号及是否接受差异。报告与页面数据一起进入版本快照，AI 修改上下文不发送这份只供追查的元信息。

## 支持矩阵

| 内容 | 当前行为 |
| --- | --- |
| 矩形、椭圆、直线、贝塞尔路径 | 转为可编辑元素，保留位置、尺寸、翻转和旋转 |
| 四角圆角、透明描边矩形 | 保留圆角，统一/独立圆角均可；旧版已导入的标准轮廓矩形可恢复圆角 |
| 纯色和透明度 | 保留颜色及填充透明度 |
| 线性/径向渐变、多重填充 | 按顺序保存为结构化绘制属性，支持显示；属性面板可改成纯色，尚无完整渐变编辑器 |
| 多重描边、内/中/外描边、虚线、线帽与连接 | 按结构化样式显示和保存 |
| 图形外阴影 | 保留偏移、模糊、扩展和颜色 |
| 文字 | 保留对齐、行高、字距、单/多行；优先原字体族，缺失时回退；最小字号 12px，源稿更小时会报告差异 |
| 混合文字 | 保留各段字重、颜色、字号比例和透明度；整段改写文字后使用基础样式，尚非富文本编辑器 |
| PNG/JPEG/GIF/WebP | 自动提取为页面内嵌图片；不依赖原文件路径 |
| 分组 | 展开为画布元素，保留来源分组用于多选操作；不是完整嵌套容器编辑系统 |
| 轮廓蒙版 | 支持矩形、椭圆和路径的蒙版链、嵌套变换和解除蒙版；内容继续可编辑 |
| 组件实例 | 展开并隔离实例分组；支持可定位的文字、组件替换、图片和显隐覆盖 |

以下内容仍有边界，必须在报告中明确说明，不能宣称完全还原：

- 布尔组合路径当前按复合路径处理，不能保证复杂交叠区域正确。
- 分组整体透明度按子图层展开，交叠区域可能不同；分组整体阴影未保留。
- 透明度蒙版、复杂组合蒙版、内阴影、背景/图层模糊、图案填充、角度渐变、混合模式、调色、特殊路径端点和特殊圆角风格。
- 不可定位的嵌套组件覆盖、共享样式覆盖，以及组件改变尺寸后的原生自适应约束。
- 混合段落的不同对齐/行距；本机未安装的字体；不同色彩配置下的逐像素一致性。
- 设计稿业务交互不会凭空生成，需要在原型中配置。

## 运行边界

- 单文件 64MB；单条 ZIP 解压内容 256MB，总解压量 1GB，检查目录、压缩方式、重复/加密条目和 CRC。不向磁盘解压用户提供的 ZIP 路径。
- 上传临时文件绑定账号和项目，成功、取消、退出服务或等待 15 分钟后清理。
- 独立转换子进程，最多两个并行任务，单任务 90 秒超时、JavaScript 堆上限 2GB；取消会终止任务。页面只在结果通过验证后写入。
- 单页最多 20,000 个元素、转换结果最多 8MB。过大时明确拒绝；不截断图层来凑成功结果。

## 回归证据与执行方式

1. `npm test`：绘制属性、文字、实例覆盖与隔离、轮廓蒙版、ZIP 校验、权限、预检查确认、失败不落库和报告保存等单元/API 检查。
2. `node tests/run-browser.mjs sketch-drawing.browser.mjs`：由独立人工 SVG/CSS 参考图验证渐变、填充、虚线、阴影、内外描边、蒙版；比较像素并验证保存后继续编辑。参考图不从转换结果生成。
3. `node tests/run-browser.mjs sketch-upload.browser.mjs`：上传、预检查、接受差异、查看报告、新页面自动打开、同名追加、刷新恢复。可设置 `SKETCH_TEST_FILE` 使用真实文件。
4. `npx tsx scripts/audit-sketch.ts "C:\path\企财.sketch" "财务报表,辅助核算,凭证模板,账套设置"`：检查四个分类的全部 30 个业务画板，生成 `test-results/sketch-audit/manifest.json` 和逐画板结果。这是批量结构检查，不是 30 页外观验收。
5. `sketch-accuracy.browser.mjs`：现金流量表的 44 处金额单行和右对齐、SVG 坐标、按钮圆角回归；可用 `SKETCH_REFERENCE_PREVIEW` 指定已人工确认匹配此画板的 Sketch 内嵌预览，比较排除字体差异区域后的图形。文件内只有一张预览，不能拿它验证其他画板。

浏览器用例由测试运行器创建独立数据库，不向工作项目插入测试页面。所有输出在被 Git 忽略的 `test-results/` 中。新增绘制能力必须新增对应人工参考或源稿回归样本；存在明确差异的设计稿不能仅凭转换数量宣布验收通过。

文件结构参考：[Sketch 官方文件格式](https://developer.sketch.com/file-format/)、[格式版本说明](https://developer.sketch.com/file-format/versioning)。
