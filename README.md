# Forma · 原型设计

基于 React、TypeScript、Ant Design、Moveable、Selecto、Zustand、Fastify、SQLite 和 Drizzle ORM 的本地原型设计系统，支持页面设计、交互预览、标注、固定版本与细粒度项目权限。

## 启动

Windows 局域网部署可直接双击根目录的命令文件，服务器电脑先安装 Node.js 22 或更高版本，并复制完整项目文件夹。首次安装依赖需要联网；不需要从开发电脑复制 `node_modules`。

| 命令文件 | 用途 |
| --- | --- |
| `start-lan.cmd` | 启动正式服务；首次自动安装依赖、构建和迁移，显示本机和局域网访问地址 |
| `update-server.cmd` | 更新依赖、重新构建、迁移数据库并启动；适合复制新版程序后运行 |
| `backup-data.cmd` | 单独备份正式数据库，可在服务运行时执行 |
| `start-dev.cmd` | 启动本机开发环境，默认使用独立的开发数据库 |
| `allow-lan.cmd` | 右键「以管理员身份运行」，放行同一子网的访问；首次需要或端口变化时执行 |

平时双击 `start-lan.cmd` 即可，服务窗口保持打开，停止时按 Ctrl+C。防火墙放行适用于专用网络或域网络，默认端口为 6060，可在 `.env` 修改 `PORT`。

**以后升级只做三步：**

1. 在旧服务窗口按 Ctrl+C 停止服务。
2. 复制新版程序覆盖原目录，保留服务器原有的 `.env`、`data/` 和 `backups/`。
3. 双击 `update-server.cmd`，等待显示访问地址。

命令文件不会自动下载新版代码。生产启动和升级都会先把现有数据库备份到 `backups/时间编号/`，再执行尚未执行过的数据库迁移；备份包含 SQLite 日志中尚未合并的数据。任一步骤失败会停止，并保留错误信息。开发默认用 `data/forma.dev.db`，生产默认用 `data/forma.db`；通常不要设置 `DATABASE_PATH`。AI 功能还需要在服务器上安装并登录所用的 Codex / Claude CLI。

以下是手动命令方式：

命令文件安装依赖时使用 `npm ci --include=dev --ignore-scripts`，再执行 `npm rebuild esbuild` 并验证 SQLite 的内存读写。当前锁定的 `better-sqlite3 13` 已自带 Windows x64/ARM64 预编译模块，这样可避免 npm 从锁文件安装时误触发原生编译。下面的手动安装如遇到 `node-gyp` 错误，也可改用这两个命令。

需要 Node.js 22 或更高版本。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:6060 。首次访问创建管理员账号；开发时 Fastify 和 Vite 共用一个端口，API 与前端同源。

```sh
npm run build
npm start
```

以上为生产构建与启动方式；生产模式由 Fastify 提供构建后的静态文件和 API。可通过 `PORT` 环境变量修改端口。服务默认仅监听本机；团队共享时在同一台服务器启动，将 `HOST` 设为 `0.0.0.0`，其他成员访问这台服务器的地址。各自启动独立服务和数据库不会形成协作。

## 账号、权限与页面协作

没有账号时显示「创建管理员账号」。第一个成功创建的账号自动成为系统管理员，现有项目归属给他，原型内容和版本保留。初始化在事务中完成，两个窗口同时提交也只会产生一个管理员；初始化完成后关闭公开注册，不提供默认账号或默认密码。用户名为 2–32 位字母、数字、下划线、点或连字符（支持中文、不区分大小写），密码为 8–128 位。

登录后点击右上角账号菜单 →「账号与项目权限」，系统管理员可创建成员账号，并为当前项目分配无权限、只读、可编辑或项目管理员。项目管理员可管理本项目成员；项目创建者的管理员权限不能移除。成员也可以创建自己的项目。系统管理员可访问所有项目。没有项目权限时显示空项目入口，不会加载其他人的项目。

密码使用随机盐与 scrypt 哈希；登录使用服务端 Session 和 HttpOnly、SameSite=Strict Cookie，有效期 7 天，退出后立即失效。服务端逐请求校验身份和项目权限，保存、页面/项目管理、AI 以及预览读取均受保护。登录失败有频率限制，浏览器跨站写入会被拒绝。

打开页面、选中元素和移动画布不占用编辑权；实际修改或发起 AI 对话时自动取得当前页编辑权，并核对服务器最新内容，避免覆盖其他人的修改。编辑权绑定用户、登录 Session 和独立窗口；同一账号开两个窗口也不能同时编辑同一页。别人正在编辑时显示简短提示，每 15 秒同步已保存内容；不同页面可以同时编辑。最后一次修改后空闲 60 秒，且内容已保存、AI 没有运行时自动释放，无须手动结束编辑。保存失败或存在冲突时保留编辑权，等待处理。编辑窗口每 15 秒续期，断线未续期 90 秒后释放；关闭页面、切页或退出登录也会释放。降为只读或移除项目权限会清理相应编辑权。

AI 修改需要当前窗口拥有编辑权，结果返回时再次校验权限、编辑权与文档版本；生成期间丢失编辑权不会应用结果。版本冲突保护仍然保留。此版本采用页面独占编辑和轮询同步，没有同一页面多人同时修改的 CRDT 或在线光标。账号和权限保存在现有 SQLite 数据库中，启动时自动迁移。

## 本版范围

- 多项目、多页面和多级子页面；每页独立画布，支持矩形、椭圆、文本、直线，以及当前 Ant Design 5.29.3 的可视组件和常用输入变体，共 75 个组件入口。
- 拖入 / 点击添加，拖动、调整尺寸、旋转，框选 / Shift 多选，多元素移动与缩放，对齐、边缘和网格吸附。
- 右侧属性编辑，文字双击编辑，图层排序、隐藏、锁定，复制粘贴、删除、撤销重做。
- Select 选择器的实例属性：选项增删改和上下排序、默认选中项、单选/多选、允许清空、禁用。角色与状态都是独立的示例配置，不含按名称判断的特殊逻辑。
- 画布缩放、平移；基础图形、文字和按钮可配置点击弹窗、消息、切换目标显示；独立标签页的项目预览。
- 平移工具选中后按住鼠标左键拖动画布；也可按住空格临时平移或直接按住鼠标中键拖动。平移不受画布大小和滚动范围限制，不改变元素坐标。滚轮移动视野，Shift+滚轮横移，Ctrl/Cmd+滚轮缩放；「适应画布」恢复视野，V 返回选择工具。
- 弹窗为独立可编辑容器，可修改标题、内容尺寸、背景，并编辑内部元素。弹窗中的按钮支持关闭、校验表单并关闭；输入框支持必填和邮箱校验。
- 服务端读取 SQLite 中的原型文档；自动保存、手动保存、保存失败重试和多窗口版本冲突保护。
- 表格支持自定义列、模拟数据、分页、多个行操作按钮、行弹窗与关联控件筛选；元素支持根据页签或选择器的当前值显示。
- 弹窗复选框支持全选、半选和至少选中一项校验；配置「应用弹窗选项并关闭」后，确定才更新表格列，取消放弃本次修改。
- 画布底部悬浮 AI 输入框，支持自然语言修改当前页面、选中元素及弹窗内容；流式回复、停止生成、整轮撤销和对话历史恢复。

文档保存在本机 SQLite 数据库，刷新和重启服务后恢复最近保存内容，并记住本浏览器上次打开的页面。原型设计的独立文件夹／资源文件管理尚未实现。旧版成员示例表格保留原样，可点击「自定义表格」改用配置数据；通用新增记录提交尚未实现。输入框等控件的原生输入行为仅在预览中启用。分组和通用嵌套容器尚未实现。

## 页面入口

系统首页 `/` 与登录后的默认入口直接进入原型设计，`/design?projectId=…&pageId=…` 继续支持直接打开指定项目和页面。左上角 Logo 返回当前项目首页；账号菜单进入独立的 `/manage` 管理中心，保留成员、角色、系统账号、项目设置和权限审计。旧 `/workbench` 地址会转到原型设计。

研发工作台、需求／任务／缺陷、研发迭代和工作流已移除。研发测试数据和归档表已通过 `0010_remove_rd_test_data` 迁移清理，不保留研发数据备份，也不再限制原型版本删除。旧产品／开发／测试内置角色转换为只读成员，自定义角色保留原型权限并移除研发权限；已有账号、项目、原型文档、标注、版本及项目权限继续保留。历史迁移文件继续保留，以支持已有数据库升级。

## Ant Design 组件库

在左侧「元素」中按通用、布局、导航、数据录入、数据展示、反馈及其他分类查找组件；支持中文名称和英文组件名搜索，分类可折叠。点击或拖入后，在右侧「内容 → 组件设置」修改组件专属属性。选项、菜单、卡片、表单、时间轴等的条目和正文都是实例数据；副本独立，支持撤销、自动保存和重载。新增组件也可通过 AI 添加和修改。

日期和时间选择、单选、数字、评分、滑块、级联和树选择、颜色、菜单、分页、折叠、轮播、消息、通知、确认框及引导均可在预览体验。Upload 仅演示本地文件列表，不发送文件；Form 只做模拟校验和提交。界面文字最小 12px，画布整体缩放仍按用户选择生效。

Flex、Grid、Layout、Space 和 Splitter 提供可配置的布局示意与条目，暂不承载其他画布元素的拖入嵌套。Modal/Drawer 组件可编辑标题和正文，在预览点击后打开；需要任意组合子元素的弹窗，继续使用「弹窗 → 新建」与「编辑目标弹窗」。Grid 使用实际 Row/Col 渲染；App 和 ConfigProvider 由编辑器及预览内部统一提供，hooks、主题 API、工具函数不作为可拖拽元素。以当前安装的 v5 为边界，不自动升级至 v6。

组件定义统一放在 `shared/antd-catalog.ts`，供组件库、属性面板、文档校验及 AI 使用。配置只接受已登记的可序列化属性，服务端拒绝未知字段、非法类型和循环条目。`antd-components.test.ts` 检查已安装 antd 导出覆盖、配置与 AI 校验；`antd-components.browser.mjs` 在隔离数据库中验证所有组件渲染、编辑保存及典型预览交互。

## 项目迭代版本

右侧「设计 / 交互 / 版本管理」的「版本管理」中，管理员可选择「确认新的迭代版本」，填写名称与说明后固定当前项目的全部页面。创建前保存当前页面，并核对项目清单；若页面、层级、项目名或文档版本在核对后变化，则拒绝确认并要求重新核对。其他窗口持有编辑权或项目中 AI 仍在生成时，也会提示等待。快照只包含已保存的原型数据，其他窗口尚未提交到服务器的内容不会被静默纳入。

「查看版本」在新窗口打开只读的固定版本预览，URL 携带 versionId，页面切换和刷新都继续读取这个版本。页面改名、删除、调整层级及后续草稿编辑不会改变快照。版本不可就地编辑；「新建草稿」完整复制历史版本为独立项目，并自动赋予创建者管理员权限，当前项目和历史版本保留。历史版本仍受所属项目权限控制；项目删除后，其版本及链接随之删除。

版本由项目清单和内容哈希组成：相同页面内容只存一次，页面名称和层级按版本单独保存；内嵌图片按字节内容去重，快照中的图片引用独立固定资源。新建草稿时把图片恢复为内嵌数据，因此删除原版本不影响新草稿。外部 URL 或 blob 临时图片不能保证内容固定，确认版本会提示先换成内嵌图片，不会悄悄把可变图片当作固定资源。上传控件的演示文件列表本身不持久化，不作为资源快照。

管理员删除版本前需要确认；其他版本和工作草稿保留，只清理没有任何版本引用的页面内容和资源。SQLite 释放的数据库页可复用，不自动执行会锁库的 VACUUM。版本不保存项目源码、依赖、登录会话、编辑锁或 AI 聊天历史。不提供历史版本就地覆盖当前项目或分支合并。

## 表格行操作与模拟数据

选中配置表格，在右侧「内容 → 行操作按钮」添加按钮，自定义文字、显示消息或打开已有弹窗；「新建并编辑弹窗」会创建独立的普通弹窗并关联当前按钮。多个按钮可打开不同弹窗，同一弹窗也可被不同表格复用。旧版行操作提示继续兼容。

弹窗标题、文本和消息可使用 `{{row.name}}` 引用当前行的 `name` 字段，字段名可在「编辑模拟数据」中查看。选中弹窗内的输入框或选择器，在「当前行数据 → 绑定当前行字段」选择字段，预览打开时自动回填。Select 字段保存选项值（ID），多选以逗号分隔。

弹窗确认按钮在「交互」中可选择「更新当前模拟行并关闭」或「删除当前模拟行并关闭」。更新会校验表单，只写回本弹窗绑定的字段；取消、关闭或 Escape 放弃修改。只需确认后显示提示时，可使用原有「校验表单并关闭弹窗」，消息也支持当前行字段。分页和筛选后仍操作实际点击的原始行。

这些更新和删除只影响当前预览，刷新恢复文档中的模拟数据，不会保存成业务数据。AI 同样可以生成上述行操作、弹窗、字段绑定及确认动作。跨页面跳转、表达式和通用变量仍未提供。

## 底部 AI 助手

AI 输入框悬浮在中间画布底部，不占用布局高度，左右组件栏和属性栏保持原位。默认收起整个聊天浮层，使用 Ctrl+~（Esc 下方的反引号键，也支持 Ctrl+Shift+该键）显示或隐藏，并记住显隐状态。在聊天输入框和属性输入框中也可使用；按住快捷键不会反复切换。隐藏保留草稿、对话和展开状态，正在生成的请求继续执行；打开后点击输入框旁的对话图标展开或收起记录，均不会改变画布尺寸或缩放。鼠标停留在输入框内的机器人图标上可查看当前页面、弹窗及选区范围。各页未发送的草稿保存在本浏览器，Enter 发送，Shift+Enter 换行。

选中元素后可输入「把这个按钮改成蓝色」「给表格增加联系人列」；未选中时默认处理当前页面。模型输出经过原型操作协议和校验后，整轮应用到编辑器并走既有自动保存。可使用画布工具栏撤销或 Ctrl+Z 逐步撤销修改。生成期间继续手工编辑不会被覆盖；切页会停止当前生成。停止、连接中断、不合法输出和不支持的组件不会应用不完整的修改。对话按页面隔离，保存在独立的 `ai_messages` 表中，删除页面时随页清理。

AI 使用与服务端校验一致的属性 Schema。修改表格时可只提供变化的配置项，未提供的列、模拟数据、分页和筛选保持原样；数组字段整体替换。模型结果不符合协议时会携带具体字段错误自动修正一次，修正成功后整轮应用；仍失败则显示字段原因并保留原文档。登录、网络和调用超时不走属性修正重试。

模型调用、对话接口和存储均由本项目提供，不依赖任何其他项目的服务、接口、代码包、数据库或配置。当前通过本机 Codex / Claude CLI 登录调用模型；不另建模型账号，不在浏览器暴露凭据。Codex 的非交互结构化输出参数依据 [OpenAI Docs](https://learn.chatgpt.com/docs/non-interactive-mode) 实现。

需要调整引擎时，把根目录 `.env.example` 复制为 `.env` 并修改，重启服务生效。默认 `FORMA_AI_PROVIDER=auto`，先用 Codex，仅在明确额度耗尽时接续 Claude；可设为 `codex` 或 `claude` 固定引擎。网络、登录错误和普通 429 不切换引擎。`FORMA_CODEX_CLI` / `FORMA_CLAUDE_CLI` 可指定本机绝对命令路径（可执行文件或 `.js/.mjs`），npm 全局安装通常自动识别；`FORMA_CODEX_MODEL` / `FORMA_CLAUDE_MODEL` 可选，默认沿用 CLI 模型配置。Codex 沿用本机 CLI 登录和接口连接配置，不读取其他业务项目配置；调用在临时目录中以只读方式运行，并关闭内置执行类工具。`FORMA_AI_TIMEOUT_MS` 默认 120000，最长 300000。

原型和设计稿的 AI 输入框支持在输入框内直接粘贴 PNG/JPEG 图片。每条消息可附一张图片，最大 6MB、8000px、2000 万像素；发送前可预览或移除，也可仅发送图片。图片作为本轮参考传给模型，不会直接插入画布；失败或停止后保留附件以便重试。附件本身不写入历史或草稿缓存，历史只保留附图标记，后续需要查看原图时请重新附图。

本版支持当前页面内的图形、表格、选项、弹窗和现有交互配置；暂不通过底部对话新增项目、跨页修改或编写新组件代码。图片重建通过「项目页面」旁加号菜单的「图片生成原型」入口使用。AI 历史只保存对话和应用状态，刷新后使用普通撤销历史无法撤销上一编辑会话中的修改。

登录凭证失效（例如 `invalid_refresh_token`）会立即结束本轮，并明确提示重新登录；不会等待到超时或自动切换引擎。Codex 可在终端执行 `codex login` 重新登录。登录未恢复前，原型不会发生修改。

Codex 默认启用系统代理兼容，并对已有自定义 provider 关闭 WebSocket 传输；可通过 `FORMA_CODEX_SYSTEM_PROXY=false`、`FORMA_CODEX_DISABLE_WEBSOCKETS=false` 保留原传输行为。可临时设置 `FORMA_AI_DIAGNOSTICS=true` 在服务端输出事件类型，诊断日志不输出提示词、凭据或模型正文。若本机真实模型连接超时，应检查 CLI 登录、接口连接及代理设置；模型命令存在不代表已验证远端可用。

## 账套选择原型

参考 `finance-admin` 中账套选择模块制作的独立可编辑页面，使用虚构组织和账套数据。左侧「页面」中选择「账套选择」，点击「预览原型」体验正常/停用页签、组织树搜索和筛选、关键词查询、组织级别和账套状态筛选、分页，以及自定义视图弹窗。

选中表格可在右侧修改列标题、模拟数据、每页条数及筛选关联；选中页签、树或复选框组可编辑选项和默认值。通过「自定义视图」按钮的交互面板进入目标弹窗编辑，也可在左侧元素面板的弹窗列表进入。

本次没有产品扫描入口。`examples/account-select.ts` 仅记录本次制作的原型数据，`scripts/add-account-select.ts` 是向明确指定已有项目写入新页面的一次性脚本；不在启动时运行，遇到同名页面会停止。预览时的筛选和列选择不写回原型文档，重新预览恢复组件配置的默认值。「进入」仅提示，不连接财务系统的权限和路由。

## 项目预览

点击「预览原型」会先保存当前修改，再在新标签页打开整个项目。左侧显示可展开和收起的页面/子页面树，默认选中并打开编辑器当前页面，点击树节点切换原型；编辑器保留在原标签页。

预览地址为 `/preview?projectId=项目ID&pageId=页面ID`，可直接打开或刷新，支持浏览器前进/后退。页面必须属于指定项目；无效页面回退到该项目的有效页面，项目不存在时显示错误和重试。预览中的输入、筛选和弹窗状态不会保存到文档，也不会改变编辑器最近打开的页面；切页后重新初始化交互状态。

「刷新」重新读取项目和原型数据；「返回编辑」关闭预览标签页，直接打开的预览链接则回到编辑器。保存失败或有版本冲突时停止打开预览，保留当前编辑内容。从弹窗编辑状态打开预览时，默认显示该弹窗。

## 项目、页面和子页面

- 左侧「页面」面板顶部下拉切换项目，旁边「+」新建项目，「···」重命名或删除当前项目。
- 左侧「页面」页签显示页面树；「+」或「新建页面」创建根页面。
- 每个页面右侧「···」可新建子页面、重命名、复制此页、移动层级、上移/下移或删除。
- 点击页面名称切换独立画布。子页面本身也有原型内容，不是纯文件夹；「复制此页」只复制当前页面内容，不复制子页面。
- 「移动页面」可以选择其他父页面或项目根目录，禁止移动到自身或后代下；本版不支持跨项目移动。
- 切页前先保存当前修改；保存失败或冲突会阻止切换并保留当前内容。画布的撤销历史按当前打开的页面处理，不会把其他页面的内容撤销进来。
- 删除父页面会一并删除全部后代；删除项目会删除其中所有页面。删除有确认提示，画布撤销不能恢复管理操作。至少保留一个项目，每个项目至少保留一个页面。

页面层级保存在 `pages.parent_id`，每个页面的原型 JSON 单独保存在 `documents`。升级数据库时增加层级字段，原有页面和内容保留。

## 保存与数据库

编辑停止约 600ms 后自动保存；右上角显示「等待保存 / 正在保存 / 已保存」。首次取得编辑权后的修改立即保存，也可按 Ctrl/Cmd+S 立即保存。保存请求串行执行，期间继续编辑的内容会在下一次请求保存。等待显示「已保存」后关闭；有未保存修改时浏览器会提示离开确认。

保存失败时，当前窗口保留修改并显示重试按钮；其他窗口已更新同一页面时，服务器返回版本冲突并拒绝覆盖。核对本地修改后，可确认「重新载入」来读取服务器版本。这是覆盖保护，不是实时协同编辑。

- 数据库按启动方式分开：`npm run dev` 使用 `data/forma.dev.db`，`npm start` 使用 `data/forma.db`。现有 `data/forma.db` 保留为生产库，不移动、不复制或清空；开发库首次运行时独立初始化，账号、项目、页面、图片、版本和聊天记录互不共享。
- 可通过 `DATABASE_PATH` 显式指定其他数据库，自动化测试继续用它指向临时库。该变量会覆盖环境默认路径；如果在公共 `.env` 中将它固定为同一路径，开发与生产仍会共用，所以正常使用无需设置它。
- `data/` 和 SQLite 数据文件不纳入 Git；`drizzle/` 中的 SQL 迁移和元数据纳入 Git。
- 首次启动自动创建默认项目与页面；后续启动只应用缺失迁移，不覆盖已有文档。
- SQLite 开启外键、WAL 和写锁等待；页面 JSON、版本号及元信息在事务中保存。
- 表结构：`projects`、`folders`、`pages`、`documents`、`assets`。项目和页面树已经接入；独立文件夹及资源表为后续文件管理准备，当前不提供资源上传界面。
- 需要备份时，先停止服务，再复制整个 `data/` 目录。

修改 `server/db/schema.ts` 后运行 `npm run db:generate` 生成迁移；`npm run db:migrate` 应用到开发库，`npm run db:migrate:production` 应用到生产库。正常启动时也会向当前环境的数据库应用缺失迁移。运行时使用 Drizzle ORM 和 better-sqlite3，迁移工具为 Drizzle Kit。

接口：`GET /api/bootstrap` 返回默认页面、项目元信息及文档版本；`GET /api/projects`、`GET /api/projects/:projectId/pages` 列出元信息；`GET/PUT /api/pages/:pageId/document` 读取与保存文档。保存请求携带 `{ revision, document }`，格式错误返回 400，旧版本覆盖返回 409。

`GET /api/bootstrap?pageId=...` 打开指定页面，页面已删除时回退到有效页面；`POST /api/projects` 新建项目及首页，`PATCH/DELETE /api/projects/:projectId` 重命名/删除；`POST /api/projects/:projectId/pages` 创建页面（可传 `parentId`），`PATCH/DELETE /api/pages/:pageId` 更新层级/名称/顺序或删除，`POST /api/pages/:pageId/duplicate` 复制此页。

## 编辑弹窗

1. 选中页面中的按钮，在右侧「交互」中选择「打开弹窗」。首次设置会自动创建对应弹窗，也可以选择已有弹窗。
2. 点击「编辑目标弹窗」，或从左侧「元素 → 弹窗」列表进入。主页面变暗，画布显示弹窗及其内部元素。
3. 从左侧添加元素，拖动、调整尺寸和修改属性。选中为空时，右侧可以修改弹窗标题、内容宽高和背景。按 Escape 清除选择可回到这些设置。
4. 在弹窗内选中按钮，可以配置「关闭弹窗」或「校验表单并关闭弹窗」；选中输入框可以设置必填和校验类型。
5. 点击「返回页面」继续编辑主页面；预览时按钮打开绑定的弹窗。如果直接从弹窗编辑状态预览，会先打开当前弹窗。

弹窗和页面的元素、图层及尺寸相互独立，编辑记录使用同一套撤销重做。左侧「新建」可以创建其他弹窗，再绑定到页面按钮。

## 原型标注层

在画布上方点击「标注」，或在右侧选择「标注」页签，点击「添加标注」后在画布放置编号，并填写标题和说明。点击编号或列表可查看说明；「重新定位」可更换位置，Esc 取消放置。标注可删除、撤销和重做，不占用普通原型图层。页面与弹窗分别显示各自的标注，位置会随画布尺寸按比例变化，每页最多 500 条（含弹窗）。

标注随页面自动保存，也会保留在固定版本和复制的页面中。显隐只是当前窗口的查看设置，不会修改原型内容。预览默认隐藏标注，点击预览工具栏的「标注」后可点击编号查看说明。只读成员可以查看，新增与修改沿用原型编辑权限和页面编辑占用机制。旧原型文档可直接使用，无需数据库迁移。

## 账号与权限管理

管理员从右上角账号菜单进入「账号与项目权限」，跳转到独立的 `/manage` 管理中心页面。进入前会保存当前原型，页面提供项目选择和返回原型设计入口；栏目地址支持直接打开与刷新。项目成员支持搜索、角色筛选、添加成员、确认调整角色、移除成员及查看有效权限来源。系统管理员可管理全部项目，项目所有者拥有完整项目管理权限。

「角色与权限」提供只读成员、原型设计者、版本负责人、兼容编辑成员和项目管理员。可复制内置角色为当前项目的自定义角色，分别配置原型编辑、页面管理与删除、Sketch 导入、版本复制与发布、版本删除和项目信息修改。成员与角色管理能力不向自定义角色下放。修改角色显示新增、撤销的权限和影响人数；旧配置不能覆盖其他管理员已保存的新配置。删除角色时必须选择替代角色，成员迁移和角色删除在同一事务完成。

系统账号管理支持创建成员、启停、控制创建项目资格和重置密码。停用或重置密码立即使旧登录会话失效；撤销编辑权限会释放页面编辑占用。创建账号不自动加入项目。新项目的删除和所有权转交仅允许所有者或系统管理员操作；已有项目管理员和编辑成员的旧能力在迁移时保留。

项目管理员可查看当前项目最近 500 条权限变更记录，系统账号变更记录仅系统管理员可见。记录支持按操作者、目标、操作和开始日期筛选，密码不会写入记录。前端定期刷新权限，服务端每次操作重新校验，后台撤权即时生效。

数据库启动时自动执行新增迁移，保留已有账号、密码、项目归属与原型数据。系统仅保留原型设计及账号、项目权限管理。

## 编辑 Select 选项

从左侧「业务组件」拖入「Select 选择器」，或搜索 `select`、`选择器`、`下拉框`。选中实例后，在右侧「设计 → 内容 → 选项列表」修改选项；下面可以设置默认选中项、多选、清空和禁用。角色选择器位于「新增成员」弹窗内，需要先进入弹窗编辑。

## 普通图片粘贴

普通图片可直接在画布按 Ctrl+V（macOS 为 ⌘V）粘贴为「图片」元素，不经过 AI。支持剪贴板中的 PNG、JPEG、GIF、WebP，单张最大 4MB，一次最多 10 张，粘贴后页面总内容不超过 8MB。初次插入保持比例并适配画布大小，支持移动、调整大小、复制、撤销和自动保存；在弹窗编辑中粘贴则归属该弹窗。图片内嵌保存，刷新、预览和固定版本不依赖剪贴板或临时文件。在文字输入框中粘贴继续用于文字编辑，只读时不能向画布插入图片。

## 图片生成原型

左侧项目名称右侧「··· → 图片生成原型」，选择 PNG / JPEG 图片（最大 6MB、单边不超过 8000px、总计不超过 2000 万像素），可补充页面用途和还原要求。点击「生成可编辑原型」后，模型直接接收图片，按图片尺寸重建文字、按钮、输入框、选择器和表格等组件；复用底部 AI 的本机 Codex / Claude 配置及一次属性错误自动修正。仅 Codex 明确额度耗尽时才自动接续 Claude，接续和修正均携带原图。

生成后在同一窗口对照原图和结果，满意后点击「保存为新页面」，自动打开新页面继续编辑、配置交互。同名自动追加序号；预览、失败、停止和取消不会创建空页面。当前页面在保存新页前先保存。需要同时具备页面管理和原型编辑权限；服务端在生成和保存时分别检查。可随时停止生成，每个账号同时最多生成一张图片。

每次先调用模型分析图片的组件结构和归属；没有疑问时继续生成。存在会影响结构、内容或交互的疑问时，界面先展示分析说明和最多三个问题，不交付原型、不创建页面。用户可以选择建议答案或自行填写，全部补充后点击「补充后继续生成」。模型会结合补充重新分析，仍有未解决的问题可以继续提问。更换图片或修改补充说明会使当前分析失效；待补充记录只在服务端内存保留 15 分钟，绑定账号、项目、原图和说明，服务重启后需要重新分析。分析和生成分别调用模型，因此比直接生成多一次调用。

表格滚动条使用原生横向滚动，内容宽度用 `table.scrollWidth` / 列宽控制，固定列用 `columns.fixed`。属性面板可调整「滚动内容宽度」。生成结果若把滚动条轨道或滑块标记成独立图形，会触发一次结构修正；持续失败则不交付该结果。原型图片上的讲解箭头、圈注也不会按界面组件处理，除非用户明确要求保留。这里的语义检查不能保证模型能发现所有歧义，仍需在预览中校对。

原图会发送给配置的模型服务，服务器只在调用期间保留临时附件，结束后清理；原图不随新页面持久保存。页面保存的是标准原型组件，可继续编辑、撤销、自动保存、复制和确认版本。图片识别有误差，需校对文字、布局和表格数据；不会自动恢复图片中不可见的弹窗、跳转或业务规则。第一版每轮最多 300 条操作，复杂长图建议裁剪分区生成。

表格支持独立配置表头高度、数据行高、表头及单元格背景、文字与边框颜色、列对齐和分页。图片生成时要求按图填写这些外观参数；没有分页控件时不默认添加分页。属性面板的「表格外观」可继续调整。旧文档中未配置外观的短表格会在空间允许时缩小行高，使已有数据完整显示；不把减少模拟数据行数当作布局修复。`image-table.browser.mjs` 检查四行表格在 165px 高度中完整可见、表头不换行，以及配置颜色、文字按钮颜色、编辑器与预览渲染。这些检查验证明确的渲染约束，不能代表任意图片都能像素级还原。

`tests/image-prototype.test.ts` 验证图片格式及尺寸、两种引擎的真实图片输入封装、额度接续、属性修正、权限与原子新建页面。`node tests/run-browser.mjs image-prototype.browser.mjs` 验证图片选择、原图对照、停止与重试、保存、继续编辑及刷新恢复，使用独立测试数据库和测试模型；这些测试不衡量真实模型的视觉还原率。

## Sketch 导入

在左侧项目名称右侧的「··· → 导入 Sketch」选择原始文件（最大 64MB），再选择一个画板，等待预检查报告，通过后点击「导入并新建页面」。有外观差异时需明确接受；无法转换的图层会阻止生成。每次导入会在当前项目根目录追加新页面并自动打开，同名自动增加序号；当前页面先保存，转换失败不创建空页面。页面菜单可查看保存的导入报告；只读成员可以查看报告，不能导入。设计稿导入保留绘制图层，不自动推断按钮、表格或业务交互。

文件先暂存在服务器临时目录，绑定当前账号和项目；取消、导入成功或等待超过 15 分钟会清理，未关闭的浏览器不会永久保留上传文件。单页转换结果超过 8MB 时需要缩减画板。复杂效果可能简化，导入完成会提示。服务器直接读取 ZIP 中的 JSON，不需要安装 Sketch，也不会修改原文件。

下面的脚本仍用于「企财.sketch → 凭证模板」特定样例，额外将源浮层转换为可交互弹窗：

```powershell
# 先生成转换文档和问题报告，不修改数据库
npx tsx scripts/import-sketch-voucher.ts "C:\path\企财.sketch" default-project --analyze
# 向指定项目追加一个页面，先备份数据库，遇到同名页面停止
npx tsx scripts/import-sketch-voucher.ts "C:\path\企财.sketch" default-project
```

生成「凭证模板 · Sketch 导入」，文字、基础图形、矢量路径均为可编辑元素；文字最小 12px。选择导入元素后，右侧可选择原设计分组，使用现有多选工具整体移动、缩放；这不是完整的嵌套容器编辑系统。矢量支持移动、缩放、填充和描边，不提供贝塞尔节点编辑。文字优先使用原设计字体族，缺失时使用本机字体回退；保留字重、行高、字距、对齐和单行/多行布局，保留混合文字样式；整段改写后使用基础样式。

源文件中已展开的模板浮层转换为独立可编辑弹窗。预览时点击「使用凭证模板」打开，「取消」关闭，「使用」显示模拟提示后关闭；搜索、新增等暂为演示提示，不执行真实业务。其他凭证录入区域保留为设计图层，需要继续转换为交互控件。矩形支持统一和独立圆角，透明描边矩形也保留圆角；源设计中的阴影和复杂布尔路径暂作简化，详情在 `test-results/sketch-analysis/report.json`。源文件和全部画板不复制到数据库，只保存选定画板转换后的文档及来源/检查报告。

完整支持矩阵、运行限制和可重复验收方法见 [Sketch 导入说明](docs/sketch-import.md)。

可用 `node tests/run-browser.mjs sketch-upload.browser.mjs` 验证界面上传、生成新页面、同名追加、原页面保留和刷新恢复。设置 `SKETCH_TEST_FILE` 可额外验证真实文件。运行脚本 `--analyze` 后，可用 `node tests/run-browser.mjs sketch.browser.mjs` 验证特定样例的编辑、分组选择、保存重载和弹窗；均使用独立测试数据库。

`persistence.browser.mjs` 验证自动保存与刷新恢复、请求期间继续编辑、Ctrl+S、保存失败重试、响应丢失恢复，以及两个窗口的版本冲突保护。`browser.mjs`、`dialog.browser.mjs`、`select.browser.mjs` 分别覆盖基础编辑、弹窗和 Select。

`projects.browser.mjs` 验证项目创建/切换/重命名/删除，页面和子页面创建/移动/复制/删除，页面内容隔离、切换前保存和刷新恢复选中页面。
